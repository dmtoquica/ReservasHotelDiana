# ReservasHotelDiana
# Etapa 1 – Análisis del problema

## 1. Problema identificado
El hostal gestiona las reservas por WhatsApp y llamadas,
lo que genera pérdida de información y errores en fechas.

## 2. Usuarios del sistema
- Recepcionista
- Cliente

## 3. Entrada – Proceso – Salida

### Entrada
- Nombre del cliente
- Fecha de entrada
- Fecha de salida
- Tipo de habitación

### Proceso
- Verificar disponibilidad
- Registrar la reserva

### Salida
- Confirmación de la reserva

## 4. Alcance
El sistema permitirá registrar y confirmar reservas.
No incluye pagos ni administración avanzada.

# Etapa 2 – Requisitos del sistema

## 1. Requisitos funcionales
- RF1: El sistema debe permitir registrar una reserva.
- RF2: El sistema debe permitir ingresar fechas de entrada y salida.
- RF3: El sistema debe mostrar una confirmación de la reserva.
- RF4: El sistema debe permitir seleccionar tipo de habitación.

## 2. Requisitos no funcionales
- RNF1: La interfaz debe ser clara y fácil de usar.
- RNF2: El sistema debe funcionar en navegadores modernos.
- RNF3: El tiempo de respuesta debe ser inmediato.

## 3. Actores
- Cliente
- Recepcionista
